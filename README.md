# claude-code-agents

[Claude Code](https://docs.claude.com/en/docs/claude-code/overview) のサブエージェントとスキルを組み合わせて作った、作業自動化の構成集です。
どれも Claude と相談しながら作り、実際に使いながら手直ししてきたものです。

| フォルダ | 内容 |
|---|---|
| [video-pipeline](video-pipeline/) | ショート動画を作るパイプライン。シナリオ → キャラ設定 → セリフ → 台本チェック → 動画生成プロンプト → 完成動画のチェック |
| [side-business-research](side-business-research/) | 副業アイデアを「発案 → 市場調査 → 批評 → 収益試算 → 採点」のサイクルで回すリサーチループ |

## 共通の設計方針

### 1. 司令塔（CLAUDE.md）と担当（サブエージェント）を分ける
`CLAUDE.md` には工程の順番だけを書き、実作業は `.claude/agents/` の担当に任せています。
担当ごとに使えるツールを絞る（例：チェック担当は Read / Write だけ）ことで、役割の外の動きを防いでいます。

### 2. 「作る担当」と「チェックする担当」を分ける
`script-checker` や `video-checker`、`critic` は自分では書き直さず、判定と指摘だけを返します。
差し戻しは回数の上限を決め（最大 2 回）、無限ループにならないようにしています。

### 3. 共通ルールはスキルに 1 か所でまとめる
全担当が守るルールは `video-rules` スキルに集約しています。
ルールを足すときは、そのファイルに 1 行追加するだけで済みます。

### 4. 人の承認を挟む
動画のアップロードや販売の登録など、外に出る操作は必ずユーザーの承認を待つようにしています。
AI に任せるのは「承認候補を作るところまで」です。

### 5. 推測を事実として書かせない
市場調査の担当には出典 URL を必須にし、確認できなかったものは「未確認」と書かせています。
収益試算では前提（件数・単価・手数料率）を必ず明記させています。

### 6. 見られないものは見られる形にする
Claude は動画を直接見られないので、`frame-check` スキルで ffmpeg を使ってフレーム画像を書き出し、画像として確認させています。

## 使い方

各フォルダに移動して `claude` を起動し、`/agents` で担当が表示されることを確認してから依頼します。
`side-business-research` は `run_until_1400.ps1` で、`claude -p`（非対話モード）を使ったサイクルを時間いっぱい繰り返せます。

## 開発について

このリポジトリは AI コーディングアシスタントの Claude（Anthropic）を使って作成しています。
