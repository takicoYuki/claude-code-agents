# 動画のフレーム書き出し

Claudeは動画を直接見られないため、一定間隔で静止画を書き出して確認する。

## 手順
1. 次を実行（ffmpegが必要。なければユーザーにインストールを依頼）
   ```
   python .claude/skills/frame-check/scripts/extract_frames.py <動画ファイル> --every 1
   ```
   → 動画と同じ場所に `<動画名>_frames/` ができ、1秒ごとの画像が入る
2. 書き出された画像を Read で順番に見る
3. 画像のファイル名（例：t0003.jpg＝3秒目）で問題の秒数を報告する

動きの確認が必要な場面は `--every 0.5` で細かくする。
